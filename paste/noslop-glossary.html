The terms behind leak analysis.

Short definitions of the words this site uses. Each entry gives the meaning first, then what it means in practice.

Infostealer log
A file that malware on an infected computer sends to its operator: saved passwords, browser cookies, autofill data and system details. Because it often carries live session cookies, an infostealer log can open an account even when two-factor authentication is on.
Combolist
A list of login and password pairs assembled from many earlier breaches and shared for credential stuffing. Most entries are old or duplicated, so a combolist needs verification before anyone can say which pairs still matter.
ULP file (URL:login:password)
A text dump where each line holds a website address, a login and a password, usually cut out of infostealer logs. The address shows which service the credentials open, which makes ULP files a fast route to corporate systems.
Credential stuffing
An attack that tries leaked login and password pairs against many other services, counting on people reusing passwords. It is automated and cheap, so one reused password can open several accounts within hours.
Password reuse
The habit of using the same password, or a slight variation of it, on several services. A reverse check follows these patterns, because a "changed" password is often the old one with a symbol added.
Reverse check
A Hirdman method that starts from one leaked record and follows the login, the password and their patterns through every other source. It shows which other accounts the same person exposes and what each of them reaches. How a reverse check works.
Session hijacking
Taking over a logged-in session with a stolen session cookie or token, without knowing the password. A live session passes two-factor authentication, which is why infostealer logs are checked for valid sessions.
Typosquatting
Registering a domain that differs from a real one by a typo, a swapped letter or another top-level domain, to catch mistyped traffic or to send convincing phishing. A look-alike domain with mail records set up is a stronger signal than a parked one.
Shadow IT
Services, subdomains and accounts a company runs without its security team knowing about them. Forgotten test servers and personal cloud accounts with work data are common examples.
Attack surface
Everything an outsider can reach and try to use against a company: domains, subdomains, open ports, exposed services, public files and the accounts of its people. Attack-surface reconnaissance maps it the way an attacker would.
Private leak
A breach that circulates in closed channels, sold or traded before it reaches public dumps. Data taken at this stage is fresher, and an exposure found here leaves more time to act.
Risk tier
The priority Hirdman analysts give a confirmed finding, judged by what the account or file can reach. Tiers set the order: what your team fixes first and what can wait.
