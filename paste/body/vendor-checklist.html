From the field

Infrastructure keys in a public file.

During an attack surface review we found two subdomains running a UI development tool. Its version was vulnerable to information disclosure: an environment file ended up in the public build, along with access tokens for repositories, cloud roles, databases and storage.

The domain had zero leaked emails or passwords; the attack surface review is what found the exposure. The vulnerability (CVE-2025-68429) is rated only Medium by CVSS (5.3), yet the file held working keys. With the client’s written permission we confirmed one token by accessing a repository, then gave the client all compromised secrets for rotation.
