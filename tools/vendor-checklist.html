From the field

No breaches on the domain, but infrastructure keys were exposed

During an attack surface review we found two subdomains running a UI development tool. The version was vulnerable to information disclosure: an environment file ended up in the public build, along with access tokens for repositories, cloud roles, databases and storage.

There was no leaked email or password for the domain, so breach monitoring would have shown nothing. The CVSS score rated the flaw "low" (3.1), but the file held working keys. We confirmed one token by accessing a repository, and gave the client all compromised secrets for rotation.
